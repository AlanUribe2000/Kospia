atencion al punto 2: hay que ACTUALIZAR FLUTTER.


-----------------------------------------------------------
 1) BACKEND  (carpeta: api/backend)
-----------------------------------------------------------
El archivo requirements.txt fue regenerado con las nuevas
versiones. Para aplicarlo en tu venv:

  cd api/backend
  .venv\Scripts\activate
  python -m pip install --upgrade pip
  pip install -r requirements.txt

Nota: si tu venv da errores raros, lo mas limpio es borrarlo
y recrearlo:

  cd api/backend
  Remove-Item -Recurse -Force .venv      (PowerShell)
  python -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt

Para verificar que todo quedo bien:

  python -c "import app; print('OK')"

Debe imprimir OK sin errores.


-----------------------------------------------------------
 2) APP FLUTTER  (carpeta: app)   *** IMPORTANTE ***
-----------------------------------------------------------
Se subio el SDK de Flutter a la version 3.47.6 (estable) y
se actualizaron paquetes a versiones mayores:
  - google_fonts  8.x -> 9.0.0   (requiere Flutter 3.47+)
  - cupertino_icons 1.x -> 2.0.0

PASO A: actualiza tu Flutter al canal stable mas reciente
        (debe quedar en 3.47.6 o superior):

  flutter upgrade

  Verifica con:
  flutter --version      (tiene que decir 3.47.6 o mayor)

PASO B: sincroniza paquetes y regenera el codigo:

  cd app
  flutter pub get
  dart run build_runner build          (regenera drift / .g.dart)

PASO C (opcional, para validar): compila en modo debug:

  flutter build apk --debug

IMPORTANTE (Windows): al compilar puede pedir "Developer
Mode" para los symlinks de plugins. Si aparece ese aviso,
activalo con:

  start ms-settings:developers

y activa "Modo de desarrollador".

Nota: el codigo NO necesito cambios para compilar con las
nuevas versiones (flutter analyze: 0 errores, 0 warnings).
